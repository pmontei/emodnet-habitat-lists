# emodnet-habitat-lists

Reference habitat lists and crosswalks across classification systems, used to select the habitats
that go into each **composite data product** of EMODnet Seabed Habitats, Work Package 3 (CCMAR):
GOOS Essential Ocean Variables, Vulnerable Marine Ecosystems, biogenic substrate, coralligenous,
Essential Fish Habitats and products requested by Regional Sea Conventions.

Every list is **generated by code from the official source files**, never typed by hand, so that it
is correct, traceable (each row has a `source`) and reproducible when a classification is updated.

## Tables (`data/processed/`)

| Table | Content |
|---|---|
| `systems.csv` | Catalogue of classification systems and lists (name, version, authority, source, date). |
| `habitats.csv` | All habitats of all systems, long format: system, code, name, level, parent, realm, group, description, source. |
| `crosswalks.csv` | *(next)* Correspondences between systems, with relationship type (=, <, >, #) and source. |
| `composites.csv` | *(next)* Per composite product: which habitats are included, why, by whom and when. |

Column definitions: [`docs/schema.md`](docs/schema.md).

## Usage

```bash
pip install -e ".[dev]"
ehl-build            # writes data/processed/*.csv
pytest
```

The EUNIS habitats are read directly from the `eunis_habitats.rda` file of the R package
[`{eunis.habitats}`](https://github.com/ramiromagno/eunis.habitats) (downloaded and cached in
`data/raw/`), so Python and R users share the same codes and system ids
(`EUNIS_2012`, `EUNIS_M_2019`, `EUNIS_M_2022`, `EUNIS_T_2021`). 90 empty rows present in that
table are dropped.
